Terminal 1989 — an operable CRT workstation concept by Bruce Lim

ABOUT THIS CONCEPT

TERMINAL 1989 is a fictional debug session on the VANTAGE HX-88, an invented desk machine running VX/86 0.9.4 — an operating system that never shipped. The files, the phantom-byte bug and the build that never made its booth are all fiction.

The phosphor screen is a 2D text canvas fed to a WebGL shader (adapted from the MIT-licensed threeui CRT shader): barrel curvature, aperture grille, scanlines, rolling bar, vignette and hash-noise. When WebGL is off or motion is reduced, a pure-CSS scanline and vignette fallback renders the same canvas flat.

Power-on is a CRT collapse and flash, a synthetic memory count eased against a progress curve, and a boot log printed line by line into a blinking prompt. The mini shell is a hand-rolled interpreter: history, tab completion, files to read and two toy programs drawn frame by frame inside the terminal. It pauses when off-screen or when the tab hides, and caps pixel ratio at 2.

Reduced motion: every animation collapses to its final frame and the shell stays fully usable. Touch devices get tappable command chips instead of the keyboard. HX-88, VX/86 and Halcyon Micro Systems never existed.

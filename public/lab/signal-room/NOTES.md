## Pass 2 — the addendum (text IS the signal)
- **Noise → resolve.** `fullpages/atlas-brut.aura.build/index.html` L1006–1023 (`decode()`): the real string revealed left→right while unresolved characters cycle through survey glyphs, mono-only so nothing shifts. I kept the *engine* (deterministic, seeded) but changed the mechanism: instead of swapping characters (which mutates the accessible text) every glyph owns fixed seeded offsets and the word carries a single `--n` "noise amount"; the glyph transform/opacity is computed in CSS from `--dx/--dy/--dr/--drop × --amp × --n`. One property write per word, no `filter: blur`, fully reversible from scroll. The wave that travels through the text is from `fullpages/grotesk-zero-45.aura.build/index.html` L720–737 (word spans + scrub progress → per-word `.on`).
- **Dial.** `fullpages/grotesk-zero-45.aura.build/index.html` "weight axis": horizontal rail with tick marks injected by `left: %` (L744–757), a moving tick (`railTick.style.left = wp * 100 + '%'`, L770), a numeric readout that updates only on detent change (`#wghtNum`/`#wghtName`, L415–419, L752–757), and a sticky 280vh stage (L155). Mine adds: 80 fine + 8 major CSS-gradient ticks (works with no JS), a needle snapped in px from a cached rail width (never a layout read in the loop), and a band *derived* from the layout so the carrier reads exactly 8,412.0 kHz.
- **Full-bleed canvas.** `fullpages/neuform.ai/index.html` L2706–2740: 2D trace with `dpr = min(devicePixelRatio, 2)`, sine-summed waveform, gradient/glow stroke and the readout updated inside the same rAF. Scaled to the whole viewport and moved behind the type; `fullpages/cipher-template.modulify.website/index.html` (L1) for the "canvas + text layers over a full-bleed stage, driven by scroll" arrangement. Per-glyph span splitting from `fullpages/apexsignal-saas.aura.build/index.html` L1039.
- **Scale contrast.** `grotesk-zero` hero: per-char inline-block spans at `clamp(64px,12.4vw,196px)` inside `overflow: hidden` rows (L81–88, L350–352), against 10–11px mono HUD labels and `.scene-tag` (L74–76).
Rejected for this pass: GSAP/ScrollTrigger/Lenis (the requirement is one rAF loop with one scroll read and no layout reads in the loop — the references lean on scrub tweens); `filter: blur` reveals; the marquee interlude, stat tiles and the boxed console from pass 1 (extra widgets); `content-visibility: auto` (it changed the document height, which would have broken the dial's frequency mapping).
